A repeatable surgery process

Each stage links a measured observation to a concrete intervention and a reviewable artifact. Development selection is not fresh confirmation. Known steering, pruning, copying and cloning are methods, not novelty claims.

1. Record the unmodified model

Pin source, precision, tokenizer and input IDs. Allow adequate completion. Save actual replies, token choices, termination and executable outcomes before comparing an edit.

2. Observe a native trajectory

Capture actual post-gating MLP values with a read-only hook. Align processed and predicted tokens. Retain compact channel/layer statistics and failures, including incorrect programs.

3. State a causal hypothesis

Specify the coordinates, positions and proposed effect. Activity is a candidate signal. Freeze the edit, strengths, random matching and all endpoints before new intervention outputs.

4. Apply one declared operation

Use scoped zeroing, actual donor values, direct weight assignments, coordinated deletion, cloning or copied modules. Keep an identity control and exact restoration. No optimizer or fitted bridge.

5. Test behavior and controls

Keep every case and condition. Evaluate executable correctness, error classes, retention, necessity, self controls and counterfactual rescue. An injected-error rescue is not an improvement over the original.

6. Save a model artifact

Store the pinned parent, exact small tensors or deterministic copy recipe, loader and source hashes under the experiment ID. Label current validation and package-replay scope. Keep private raw contexts separate.

7. Release and reduce local duplication

Review the complete candidate tree and exact diff, publish only authorized assets and verify the remote tree. Remove regenerable caches and verified duplicate exports. Preserve the evidence needed to reconstruct the result.
