Inspect activity at a specific decision

This viewer opens compact local traces. The built-in example is synthetic and is not evidence about Gemma. A unit's state belongs to the token being processed and helps predict the next token; both labels are retained.

Activity is continuous and can be signed. High activity alone is not a neuron function. Missing observations are not zeros. Raw activation times output-column norm describes a projection term before normalization, not its causal effect on the response.

Point to a cell for the token and activation.

Trace contract

Schema digital-surgery-trace-v1: tokens has processed/predicted text labels; units has layer, channel, optional down_norm and aligned values. Use null for unrecorded values. Export selected traces rather than full activation tensors. The file stays in this browser tab and is never uploaded.

The observer must first demonstrate unchanged model logits, choices, cache and state. Scientific selection, editing and confirmation are separate from this exploratory display.
